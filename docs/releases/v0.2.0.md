# Absence v0.2.0 — Personal avatars and Agent Eggs filters

[English](v0.2.0.md) | [简体中文](v0.2.0.zh-CN.md)

> These notes describe v0.2.0 as released. The Settings dialog and the panel
> layout changed in v0.3.0 and v0.5.0; later notes describe the current
> behavior.

v0.2.0 added two user-configurable areas: the agent avatar and the Agent Eggs
panel. Both were configured from a Settings dialog introduced in this release.

## User-visible changes

### Built-in character renamed to WhaleBun

The built-in HTML character was renamed to WhaleBun (鲸团团) across assets, code
and documentation. It remained the default avatar.

### Avatar skins

- The Settings dialog created a skin; the skin name was a folder under the
  server's avatar-skin directory.
- For each status (`default`, `listening`, `thinking`, `speaking`, `reading`,
  `searching`, `editing`, `running`, `waiting`, `error`), the user uploaded one
  file in mp4, gif, png, webp or svg.
- Re-uploading replaced the file; the clear action removed it.
- A status without a file fell back to the skin's `default`; a status still
  without a file used the built-in WhaleBun character. A partially filled skin
  remained usable.
- `Apply` activated the skin; switching back to WhaleBun restored the built-in
  character.
- Changes appeared without a reload or restart.
- The large avatar on Stage used the same skin as the Agent panel.

### Video upload handling

- Uploaded videos were re-encoded on the server with ffmpeg: video-only stream,
  metadata and data tracks removed, H.264 main, yuv420p, `+faststart`.
- The media endpoint supported HTTP Range requests (`206`), which `<video>`
  requires.
- A file that could not be decoded produced a hint in the panel instead of a
  broken image.

### Agent Eggs filter profiles

- The Settings dialog managed named profiles of helper command names. The
  process classifier treated a listed name as a tool, so it was folded into the
  helper count instead of appearing in the Agent Eggs panel.
- A save with an existing name overwrote the profile; a new name created one.
- The saved profile became active immediately.
- The `force` option extended filtering to the command's declared subject (for
  example, filtering `node` in `node ticker.mjs &`). A process that outlived its
  command stayed visible regardless.

### Settings dialog

At v0.2.0 the dialog had three panes:

| Pane | Configuration |
| --- | --- |
| Avatar skin | Skins, per-status uploads, activation |
| Settings | Color theme (`amber` / `blue` / `green`) and the panel order of both side rails |
| Eggs filter | Filter profiles and `force` |

The dialog was rendered through a portal, so the frameless title bar could not
clip it, and it closed on Esc or a click on the backdrop.

### Fixes

- The TABLE / Agent panel switch no longer stayed stuck as "Agent" while a skin
  was active.
- The three panes were independently scrollable.

## Breaking changes

None of the existing HTTP endpoints changed. The release added endpoints for
avatar skins and egg-filter profiles, and it changed the server's request
handling for raw uploads. Existing sessions did not need migration.

Upgrade steps:

- Restart the server and hard-refresh the browser (`Ctrl+Shift+R`); the raw-body
  parser and the media endpoint are server-side changes.
- The runtime data directories for avatar skins and egg filters were gitignored;
  the server created defaults on first boot.
- Video re-encoding required `ffmpeg` on `PATH`. Without it, the original file
  was kept unchanged.

## Known limitations

- Avatar skins and egg-filter profiles were written under the server's
  installation directory, not a user state directory. In a packaged application
  with a read-only directory, uploads failed.
- A filter profile matched command names. Processes that outlived their command
  remained visible even when their name matched a profile.
- The panel-order setting belonged to the Classic layout. It was removed in
  v0.5.0 together with that layout.
- Video re-encoding depended on the local ffmpeg build; unsupported inputs kept
  the original file.

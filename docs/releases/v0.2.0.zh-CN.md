# Absence v0.2.0 —— 个性化头像与 Agent Eggs 过滤

[English](v0.2.0.md) | [简体中文](v0.2.0.zh-CN.md)

> 本文描述 v0.2.0 发布时的状态。Settings 对话框与面板布局在 v0.3.0 和 v0.5.0
> 有变化；当前行为见后续版本的发布说明。

v0.2.0 增加了两个可由用户配置的区域：agent 头像与 Agent Eggs 面板。两者都通过
本版本引入的 Settings 对话框配置。

## 用户可见变化

### 内置角色更名为 WhaleBun

内置 HTML 角色在资源、代码与文档中更名为 WhaleBun（鲸团团）。它仍是默认头像。

### 头像皮肤

- Settings 对话框可以创建皮肤；皮肤名对应服务器头像皮肤目录下的一个文件夹。
- 每个状态（`default`、`listening`、`thinking`、`speaking`、`reading`、
  `searching`、`editing`、`running`、`waiting`、`error`）可上传一个文件，
  格式为 mp4、gif、png、webp 或 svg。
- 重新上传会替换文件；清除操作会删除文件。
- 某个状态没有文件时回退到该皮肤的 `default`；仍没有文件时使用内置 WhaleBun
  角色。只填了一部分状态的皮肤仍然可用。
- `Apply` 激活皮肤；切回 WhaleBun 恢复内置角色。
- 改动无需刷新或重启即可生效。
- Stage 上的大尺寸头像与 Agent 面板使用同一套皮肤。

### 视频上传处理

- 上传的视频在服务端用 ffmpeg 重新编码：仅保留视频流，移除 metadata 与 data
  轨道，H.264 main、yuv420p、`+faststart`。
- 媒体端点支持 HTTP Range 请求（`206`），这是 `<video>` 所需要的。
- 无法解码的文件会在面板中显示提示，不显示损坏的图片。

### Agent Eggs 过滤档案

- Settings 对话框管理按名称保存的辅助命令名档案。进程分类器把档案中的名字当作
  工具，折叠进辅助命令计数，不出现在 Agent Eggs 面板中。
- 使用已有名称保存会覆盖该档案；使用新名称会创建新档案。
- 保存后的档案立即生效。
- `force` 选项把过滤扩展到命令声明的对象（例如在 `node ticker.mjs &` 中过滤
  `node`）。无论是否过滤，活得比命令更久的进程始终可见。

### Settings 对话框

v0.2.0 的对话框有三栏：

| 栏 | 配置内容 |
| --- | --- |
| Avatar skin | 皮肤、按状态上传、激活 |
| Settings | 配色主题（`amber` / `blue` / `green`）与两侧栏的面板顺序 |
| Eggs filter | 过滤档案与 `force` |

对话框通过 portal 渲染，因此无边框标题栏不会裁切它；按 Esc 或点击背景可关闭。

### 修复

- 激活皮肤时，TABLE / Agent 面板切换不再卡在 "Agent"。
- 三栏各自独立滚动。

## 破坏性变更

现有 HTTP 接口没有变化。本版本新增了头像皮肤与 egg-filter 档案接口，并改变了
服务端处理原始上传的方式。已有会话不需要迁移。

升级步骤：

- 重启服务器并硬刷新浏览器（`Ctrl+Shift+R`）；原始请求体解析与媒体端点都是
  服务端改动。
- 头像皮肤与 egg-filter 的运行时数据目录被 git 忽略；服务器首次启动时创建默认值。
- 视频重编码需要 `PATH` 上有 `ffmpeg`。没有 ffmpeg 时保留原始文件。

## 已知限制

- 头像皮肤与 egg-filter 档案写在服务器的安装目录下，不在用户状态目录。打包为
  只读目录后，上传会失败。
- 过滤档案按命令名匹配。活得比命令更久的进程即使名字命中档案，也会保持可见。
- 面板顺序设置属于 Classic 布局，已在 v0.5.0 随该布局一起移除。
- 视频重编码依赖已安装的 ffmpeg；不支持的输入保留原始文件。
